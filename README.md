# ОСАДА ЗАМКОВ

Фэнтезийная дуэль в духе «Героев Меча и Магии» для игры по локальной сети WiFi.
Два замка на большой карте 256×256, найм войск, стены, башни, казармы и шахты.
Доход: 1 золото/сек плюс добыча шахтёров на захваченных шахтах (запасы
истощаются). Победа — разрушить замок соперника; если за 30 минут этого не
случилось, выигрывает тот, чей замок целее.

Требуется только Node.js версии 16+ — установлен он должен быть лишь на
главном компьютере (хосте). Никаких npm-пакетов не нужно.

## Быстрый старт

1. Установите Node.js с https://nodejs.org (подойдёт версия LTS).
2. Дважды щёлкните **«Запустить игру.bat»** (Windows) или выполните `sh run.sh`
   (macOS / Linux) на главном компьютере.
3. Браузер сам откроет игру. В чёрном окне сервера будут перечислены адреса
   для остальных игроков, например: `http://192.168.0.5:8080`.
4. Все компьютеры в той же сети WiFi открывают этот адрес в браузере
   (Chrome, Edge, Firefox — любой современный).
5. Как только в комнате окажутся двое — матч начнётся сам после отсчёта 3-2-1.

## Если другие игроки не видят игру

- Проверьте, что все компьютеры подключены к **той же самой** WiFi-сети.
- В чёрном окне сервера может быть несколько адресов — пробуйте адрес
  сети с названием вашей WiFi (обычно `192.168.x.x`).
- Первый запуск: брандмауэр Windows спросит про Node.js — нажмите
  «Разрешить доступ» для частных сетей.
- На странице игры в лобби видно, сколько игроков в комнате и есть ли
  связь с сервером — это подскажет, где проблема.
- Порт занят другим приложением? Запустите иначе:
  `PORT=8090 node server.js` (macOS/Linux) или в Windows:
  `set PORT=8090 && node server.js`.

## Управление

- **1 / 2 / 3 / 4 / 5 / 6 / 7** — нанять мечника / лучника / рыцаря /
  строителя / шахтёра / демонтажника / тарана. Нанятые юниты сначала встают
  в строй у своего замка.
- **Q / W / E** — выбрать стену / башню / казарму, затем щёлкнуть ЛКМ по
  любой свободной (не скалистой) клетке карты — хоть у самого замка врага,
  кроме территории замков (она скалистая). Золото спишется сразу, начнётся
  **стройка** (жёлтый пунктир и полоса прогресса). Достраивают её
  **строители**: выделите их рамкой и кликните ЛКМ по стройке — чем больше
  строителей рядом, тем быстрее. Строители и шахтёры не дерутся.
  ПКМ или Esc — отмена выбора постройки.
- **Демонтажник (6)** — рабочий: выделите его и щёлкните ЛКМ по **своему**
  зданию, чтобы снести его (возвращается половина стоимости), или по
  **дереву**, чтобы срубить его (+10 золота). Работа занимает время; несколько
  демонтажников ускоряют дело. Чужие здания он не ломает.
- **Таран (7)** — 2×2 клетки, стоит 300. Щёлкните им по чужому зданию:
  таран мгновенно сносит его и погибает. По чужому замку он наносит 25%
  оставшегося ХП и тоже погибает.
- **Свои постройки проходимы** для своих юнитов, чужие — нет. Если юнит
  оказался внутри чужой постройки, его мягко выталкивает наружу.
- **Лучники стреляют видимыми стрелами** и бьют на дистанции; башни тоже
  пускают стрелы, которые летят до цели.
- **Шахты**: захват — подвести любых бойцов к чужой/свободной шахте и кликнуть
  по ней выделенными (15 секунд, соперник может прервать, подведя своих).
  Захваченная шахта помечается флажком цвета команды. Ставьте рядом
  **шахтёров**: каждый даёт +0,25 золото/сек (+0,5 на больших шахтах в
  центре). Запасы истощаются: обычная шахта — 20 минут на одного шахтёра,
  большая — 67 минут (чем больше шахтёров, тем быстрее кончится); под
  шахтой — жёлтая полоса остатка запаса, истощённая перечёркнута.
- **ЛКМ + протяжка мыши** — выделить своих юнитов рамкой; одиночный клик по
  своему юниту — выделить его.
- **Пробел / Esc** — снять выделение.
- **ЛКМ по карте (когда юниты выделены)** — приказ: обычная клетка — идти,
  чужая постройка — сломать, чужой замок — атаковать, своя стройка — работать
  (для строителей), шахта — захватывать. На свои здания юниты не идут их
  ломать.
- **Камера**: **стрелки** или **зажатый ПКМ + движение мыши** — перемещение
  по большой карте 256×256; **«+» / «−»** (или колесо мыши) — приблизить /
  отдалить. **Мини-карта** в правом верхнем углу — щёлкните по ней, чтобы
  мгновенно перевести камеру.
- Юниты без приказа стоят и только отбиваются; сами они больше не маршируют.

## Тактика

- Стены задерживают врага, башни отстреливают подошедших, казарма ставит
  точку найма ближе к фронту — подкрепления приходят быстрее.
- Без шахтёров шахта не приносит ничего; держите её занятой, пока запас не
  истощился — потом она лишь замедляет чужих.
- Рыцарь — главный боец против стен, лучники — против живой силы на дистанции.
- Таран — точечный «выстрел» по ключевому зданию врага (башне, казарме):
  дорого, зато мгновенно. По замку он снимает четверть оставшегося ХП.
- Демонтажник убирает лишние свои стены (возвращая половину цены) и рубит
  лес, открывая новые проходы и пополняя казну.

## Баланс

Все константы (цены, урон, доход, длительность матча) — в начале файла
`server.js`. Меняйте и перезапускайте сервер.

## Состав проекта

- `server.js` — сервер и игровая логика (авторитетная симуляция).
- `public/` — страница игры, стили, отрисовка и ввод.
- `assets/` — нарисованные текстуры.
- `Запустить игру.bat`, `run.sh` — запуск двойным кликом.

## Устройство сети

Связь — обычные HTTP-запросы: клиент каждые 120 мс забирает снимок боя
(`/api/state`) и отправляет команды (`/api/cmd`). Такой транспорт
проходит через брандмауэры проще, чем WebSocket: для сети это выглядит
как обычное открытие веб-страницы. Сервер ведёт симуляцию сам, поэтому
результаты одинаковы для обоих игроков.
